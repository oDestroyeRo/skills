# Google Skills (Community Mirror)

Community mirror of Google's agent skills for Google products and technologies, with upstream updates.

Version 1.0.42. This bundle contains 220 namespaced skills.

Install in Claude Code with `claude plugin install google --marketplace oDestroyeRo/skills`.

Follow the [installation guide](docs/native-install.md) and [publishing guide](docs/native-publishing.md). See the [harness adapter](docs/harnesses.md) for runtime capabilities.

See [licenses and upstream notices](THIRD_PARTY_NOTICES.md). Upstream copyright and license notices remain under `upstream/`. `sources.lock.json` records the original Git revisions. Source symlinks are materialized as regular files for archive installation.
