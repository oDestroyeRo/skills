# tstack Skills

Theo Browne's tstack review and pull request workflows, with upstream updates.

Version 1.0.19. This bundle contains 9 namespaced skills.

Install in Claude Code with `claude plugin install tstack --marketplace oDestroyeRo/skills`.

Follow the [installation guide](docs/native-install.md) and [publishing guide](docs/native-publishing.md). See the [harness adapter](docs/harnesses.md) for runtime capabilities.
